Prosessin yhteenveto

Kuvaa vain koko prosessin kannalta keskeiset tiedot. Työkalu ei täytä organisaatiotietoja arvaamalla.

Prosessikaavio

Jokainen toimija omalla uimaradallaan. Normaali eteneminen vasemmalta oikealle.

Toimija = uimarataVaihe = tekeminenPäätös = kysymysSuositus ≤ 20 vaihetta

Vaiheiden kuvaus

Avaa vain se vaihe, jota haluat tarkentaa. Kaavion pidempi työohje kuuluu tänne, ei laatikon sisään.
